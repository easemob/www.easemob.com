    Enumeration ChatDisconnectErrorCode

    ChatConnectEventListener.onDisconnected 携带的断开连接原因码。

    这些数值与底层原生 SDK 的 EMError 错误码一致。SDK 会原样传递这些错误码且不进行过滤， 因此仍可能收到此处未列出的错误码（包括未来原生 SDK 版本新增的错误码）；该枚举仅用于提高可读性和便于比较。

    断开连接原因分为两类：

    • 登出原因：本地登录状态不再有效，用户必须重新登录。
    • 连接原因：用户仍保持登录状态，但连接已断开，SDK 会自动重连。

    除非原生 SDK 文档另有说明，否则应将收到的未列出错误码视为连接原因。

    注意：token 过期不会触发 onDisconnected，而是通过 ChatConnectEventListener.onTokenDidExpire 上报。
