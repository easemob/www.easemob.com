hyphenate_SDK_5.0

即时通讯 IM 是一个高度可靠的全球通信平台，用户可以进行一对一单聊、群组聊天或聊天室聊天。用户可以通过发送文本消息、分享图片、音频、视频、文件、表情符号和位置进行沟通。

  • EMClient 类是聊天 SDK 的入口，提供登录和登出即时通讯 IM 的方法，并管理 SDK 与聊天服务器之间的连接。
  • EMChatManager 类提供发送和接收消息、管理会话以及下载附件的方法。
  • EMMessage 类定义消息的属性。
  • EMConversation 类提供管理会话的方法。
  • EMContactManager 类提供管理联系人的方法。
  • EMGroupManager 类提供群组创建、解散和成员管理等方法。
  • EMChatRoomManager 类提供聊天室和成员权限管理的方法。
  • EMPresenceManager 类提供管理用户在线状态的方法。
  • EMChatThreadManager 类提供子区创建、解散和成员管理的方法。
  • EMPushManager 类提供配置离线推送服务的方法。
  • EMUserInfoManager 类提供获取、更新和订阅用户属性的方法。

在方法调用过程中，SDK 可能会返回错误码。详见 EMError。
