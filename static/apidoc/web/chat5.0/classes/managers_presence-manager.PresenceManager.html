addEventHandler

  • addEventHandler(id: EventHandlerId, handlers: PresenceEventHandlerMap): void

    注册 Presence 事件处理器，用于接收在线状态变更推送。

    Parameters

    • id: string

      事件处理器唯一 ID，用于后续移除。

    • handlers: PresenceEventHandlerMap

      事件处理器集合，按需实现对应回调。

    可监听事件

    PresenceEventName

    Returns void

    注册完成后无返回值。

    Example: 调用示例（注册在线状态事件）

    client.presenceManager.addEventHandler('presence-ui', {
      onPresenceStatusChange: (states) => {
        console.log(states);
      },
    });

publishPresence

  • publishPresence(params: PublishPresenceParams): Promise<void>

    发布当前用户的自定义在线状态，该状态会作为在线状态扩展描述信息保存并下发给订阅者。

    Parameters

    • params: PublishPresenceParams

      发布参数，包含在线状态扩展描述信息与可选回调。

    Returns Promise<void>

    成功时 resolve，无返回业务数据。

    Example: 调用示例（发布在线状态）

    await client.presenceManager.publishPresence({
      customStatus: 'busy',
    });

    可能出现的错误码

    Code 含义 HTTP 处理建议 可重试
    1100 发布自定义在线状态时，参数长度超出限制 400 缩短 customStatus 后重试 否

subscribePresence

  • subscribePresence(
        params: SubscribePresenceParams,
    ): Promise<SubscribePresenceResponse>

    订阅指定用户的在线状态。订阅成功后，这些用户在线状态变更时会触发 Presence 事件回调。

    Parameters

    • params: SubscribePresenceParams

      订阅参数，包含用户列表、订阅时长与可选回调。

    Returns Promise<SubscribePresenceResponse>

    返回归一化后的在线状态列表。

    Example: 调用示例（订阅用户在线状态）

    const result = await client.presenceManager.subscribePresence({
      userIds: ['userA'],
      expiry: 3600,
    });
    console.log(result[0]?.publisher);

    可能出现的错误码

    Code 含义 HTTP 处理建议 可重试
    1101 不能订阅自己的在线状态 400 从订阅列表中移除当前用户 否
    1100 参数长度超限 400 减少单次订阅的用户数量 否
