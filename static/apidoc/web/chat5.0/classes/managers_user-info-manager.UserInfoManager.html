addEventHandler

  • addEventHandler(id: EventHandlerId, handlers: UserInfoEventHandlerMap): void

    注册用户资料事件处理器，用于接收当前用户资料更新和订阅用户资料变更通知。

    Parameters

    • id: string

      事件处理器 ID，同一个 ID 再次注册会覆盖旧处理器。

    • handlers: UserInfoEventHandlerMap

      用户资料事件处理器集合。

    可监听事件

    onOwnInfoUpdated, onUserInfoUpdated

    UserInfoEventName

    Returns void

    无返回值。

    Example: 调用示例（注册事件处理器）

    client.userInfoManager.addEventHandler('profile-listener', {
      onOwnInfoUpdated: profile => {
        console.log(profile.nickname);
      },
      onUserInfoUpdated: users => {
        console.log(users.map(user => user.userId));
      },
    });

getUserInfoByUserId

  • getUserInfoByUserId(
        params: FetchUserInfoByUserIdParams,
    ): Promise<readonly UserInfo[]>

    按用户 ID 查询用户资料属性；未指定属性时查询 SDK 默认资料字段。

    Parameters

    • params: FetchUserInfoByUserIdParams

      包含 userIds 与可选成功/失败回调的参数对象。

    Returns Promise<readonly UserInfo[]>

    返回标准化后的用户资料数组，仅包含服务端命中的用户。

    Example: 调用示例（按用户 ID 查询）

    const users = await client.userInfoManager.getUserInfoByUserId({
      userIds: ['alice', 'bob'],
    });
    console.log(users[0]?.avatarUrl);

    可能出现的错误码

    Code 含义 HTTP 处理建议 可重试
    110 参数无效 - 传入非空用户 ID 数组，并确保每个用户 ID 都是非空字符串 否
    900 批量查询用户数超限 400 减少单次查询的用户数量后重试 否
    204 用户不存在 404 确认用户 ID 正确 否
    4 超过服务限制 429 降低请求频率后重试 是

subscribeUsersInfo

  • subscribeUsersInfo(params: SubscribeUsersInfoParams): Promise<void>

    订阅指定陌生人用户的资料变化；订阅成功后可通过用户资料事件处理器接收变更通知。

    Parameters

    • params: SubscribeUsersInfoParams

      包含 userIds 与可选回调的参数对象。

    Returns Promise<void>

    成功时无返回值。

    Example: 调用示例（订阅资料变化）

    await client.userInfoManager.subscribeUsersInfo({
      userIds: ['alice', 'bob'],
    });

    可能出现的错误码

    Code 含义 HTTP 处理建议 可重试
    202 用户鉴权失败 401 刷新 token 后重试 是
    210 服务未开通或无权限 403 检查服务开通状态与账号权限后重试 否
    1600 订阅人数超限 400 减少单次订阅的目标用户数量后重试 否
    1601 目标用户被订阅人数超限 400 更换订阅目标或稍后重试 否
    4 超过服务限制 429 降低请求频率后重试 是
    303 服务请求通用错误：服务端内部错误 500 稍后重试或联系服务端排查 是

updateOwnInfo

  • updateOwnInfo(params: UpdateOwnInfoParams): Promise<UserInfo>

    更新当前登录用户的一个或多个资料属性，例如昵称、头像、邮箱、手机号、签名或扩展字段。

    Parameters

    • params: UpdateOwnInfoParams

      至少包含一个可更新字段的参数对象。

    Returns Promise<UserInfo>

    返回标准化后的当前用户资料。

    Example: 调用示例（整对象更新）

    const profile = await client.userInfoManager.updateOwnInfo({
      nickname: 'Alice',
      avatarUrl: 'https://example.com/avatar.png',
    });
    console.log(profile.userId, profile.nickname);

    可能出现的错误码

    Code 含义 HTTP 处理建议 可重试
    110 参数无效 - 至少传入一个可更新字段，并确保字段值类型合法 否
    901 用户资料数据长度超限 403 缩短资料字段内容后重试 否
    204 用户不存在 404 确认用户已注册 否
    4 超过服务限制 429 降低请求频率后重试 是
