addEventHandler

  • addEventHandler(id: EventHandlerId, handlers: ChatRoomEventHandlerMap): void

    注册聊天室事件处理器，事件包括成员进出、禁言、allowlist、公告和属性变更等。

    Parameters

    • id: string

      事件处理器唯一 ID，用于后续移除。

    • handlers: ChatRoomEventHandlerMap

      聊天室事件处理器集合，可只实现需要监听的回调。

    可监听事件

    onChatRoomDestroyed, onMembersJoined, onMembersExited, onRemovedFromChatRoom, onMuteListAdded, onMuteListRemoved, onAllowListAdded, onAllowListRemoved, onAllMemberMuteStateChanged, onAdminAdded, onAdminRemoved, onOwnerChanged, onAnnouncementChanged, onChatRoomInfoChanged, onAttributesUpdate, onAttributesRemoved

    ChatRoomEventName

    Returns void

    注册完成后无返回值。

    Example: 调用示例（监听聊天室成员加入）

    client.chatRoomManager.addEventHandler('chatroom-ui', {
      onMembersJoined: event => {
        console.log(event.chatRoomId, event.members);
      },
    });

    Throws

    错误码 110：事件上下文未绑定。解决方式：先完成 SDK 初始化并注册 ChatRoomManager。

getChatRoom

  • getChatRoom(chatRoomId: string): ChatRoom

    获取绑定指定 chatRoomId 的单聊天室对象，便于后续在对象上调用成员、公告、属性等方法。

    Parameters

    • chatRoomId: string

      聊天室 ID，必填且不能为空字符串。

    Returns ChatRoom

    返回复用的单聊天室对象。

    Example: 调用示例（获取聊天室对象）

    const chatRoom = client.chatRoomManager.getChatRoom('chatroom-1');
    const detail = await chatRoom.getInfo();

    Throws

    错误码 110：chatRoomId 为空。解决方式：传入有效聊天室 ID。

joinChatRoom

  • joinChatRoom(params: JoinChatRoomParams): Promise<JoinChatRoomInfo>

    加入指定聊天室。该方法通过长连接聊天室操作发送加入请求。

    Parameters

    • params: JoinChatRoomParams

      加入参数，包含必填 chatRoomId，以及可选 ext、leaveOtherRooms。

    Returns Promise<JoinChatRoomInfo>

    返回 ACK 附带的聊天室信息；服务端未附带信息时返回空对象。

    Example: 调用示例（加入聊天室）

    await client.chatRoomManager.joinChatRoom({
      chatRoomId: 'chatroom-1',
      ext: 'from-web',
    });

    可能出现的错误码

    Code 含义 HTTP 处理建议 可重试
    4 超过服务限制：加入聊天室数量超限 403 退出不再使用的聊天室后重试，或联系服务端提升限制 否
    704 聊天室成员已满 403 等待其他成员退出后重试，或联系聊天室管理员提升上限 否
    707 用户在聊天室黑名单中 403 联系聊天室管理员将用户从黑名单移除 否
    705 聊天室不存在 404 确认 chatRoomId 正确且聊天室仍存在 否
