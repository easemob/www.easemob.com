uploadPushToken

  • uploadPushToken(params: UploadPushTokenParams): Promise<void>

    上传或覆盖设备 Push Token。成功时仅表示请求完成，不返回业务数据。

    Parameters

    • params: UploadPushTokenParams

      上传参数，包含设备标识、设备 token 与推送通道标识。

    Returns Promise<void>

    成功时 resolve，无返回值。

    Example: 调用示例（上传设备 token）

    await client.pushManager.uploadPushToken({
      deviceId: 'web-device-001',
      deviceToken: 'token-from-push-provider',
      notifierName: 'FCM',
    });

    可能出现的错误码

    Code 含义 HTTP 处理建议 可重试
    110 参数无效 - 传入非空 deviceId、deviceToken 和 notifierName 否
    1500 Push token 上传失败 400 检查登录态、deviceToken 与 notifierName 后重试 是

setGlobalSilentMode

  • setGlobalSilentMode(
        params: SetGlobalSilentModeParams,
    ): Promise<GlobalSilentModeResponse>

    设置 App 级（全局）免打扰规则，支持提醒类型、持续时长、时间区间三种模式。

    Parameters

    • params: SetGlobalSilentModeParams

      全局免打扰设置参数。

    Returns Promise<GlobalSilentModeResponse>

    返回全局规则快照。

    Example: 调用示例（设置全局提醒类型）

    const result = await client.pushManager.setGlobalSilentMode({
      rule: { mode: 'REMIND_TYPE', remindType: 'AT' },
    });
    console.log(result.rule.remindType);

    可能出现的错误码

    Code 含义 HTTP 处理建议 可重试
    110 参数无效 - 按 REMIND_TYPE、DURATION 或 INTERVAL 选择一种规则模式，并传入对应必填字段 否
    1501 免打扰设置失败 400 检查免打扰参数后重试 否

setConversationSilentMode

  • setConversationSilentMode(
        params: SetConversationSilentModeParams,
    ): Promise<ConversationSilentModeResponse>

    设置单会话免打扰规则，仅支持单聊与群聊。

    Parameters

    • params: SetConversationSilentModeParams

      会话维度的免打扰设置参数。

    Returns Promise<ConversationSilentModeResponse>

    返回目标会话与规则快照。

    Example: 调用示例（设置会话时长免打扰）

    const result = await client.pushManager.setConversationSilentMode({
      conversationId: 'group_123',
      conversationType: 'groupChat',
      rule: { mode: 'DURATION', duration: 60 },
    });
    console.log(result.rule.expireTimestamp);

    可能出现的错误码

    Code 含义 HTTP 处理建议 可重试
    110 参数无效 - 传入合法会话 ID、会话类型，并按 REMIND_TYPE、DURATION 或 INTERVAL 选择一种规则模式 否
    1501 免打扰设置失败 400 检查免打扰参数后重试 否
