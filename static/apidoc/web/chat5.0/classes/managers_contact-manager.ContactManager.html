addContact

  • addContact(params: AddContactParams): Promise<void>

    发送联系人申请。

    Parameters

    • params: AddContactParams

      目标用户与可选验证消息。

    Returns Promise<void>

    成功时仅表示请求完成。

    Example: 调用示例（发送联系人申请）

    await client.contactManager.addContact({
      userId: 'user-1',
      message: '我是 Alice',
    });

    可能出现的错误码

    Code 含义 HTTP 处理建议 可重试
    110 参数无效 - 传入非空字符串 userId；message 如需传入也必须是字符串 否
    204 用户不存在 404 确认用户 ID 正确 否
    1000 添加联系人失败：已是好友 - 根据错误原因修正后重试 否
    210 用户无权限：被对方拉黑 - 根据错误原因修正后重试 否
    1001 邀请方联系人数量已达上限 403 删除不再使用的联系人后重试，或联系服务端提升配额 否
    1002 被邀请方联系人数量已达上限 403 联系对方清理联系人列表 否

setContactRemark

  • setContactRemark(params: SetContactRemarkParams): Promise<void>

    设置联系人备注，允许传入空字符串以清空备注；设置成功后会同步刷新已有单聊会话的显示名称。

    Parameters

    • params: SetContactRemarkParams

      目标用户与备注内容。

    Returns Promise<void>

    成功时无业务返回值；若本地存在对应单聊会话，会同步更新其显示名称并派发会话列表更新事件。

    Example: 调用示例（设置联系人备注）

    await client.contactManager.setContactRemark({
      userId: 'user-1',
      remark: '产品同学',
    });

    可能出现的错误码

    Code 含义 HTTP 处理建议 可重试
    110 参数无效 - 传入非空字符串 userId，并确保 remark 为字符串；可传空字符串清空备注 否
    223 非好友不能设置备注 400 先添加好友再设置备注 否
    4 备注长度超限 400 缩短备注内容后重试 否

addEventHandler

  • addEventHandler(id: string, handlers: ContactEventHandlerMap): void

    注册联系人事件处理器，用于接收联系人关系事件；自动同步进度请在 ChatClient 级监听统一同步事件。

    Parameters

    • id: string

      事件处理器唯一 ID，用于后续移除。

    • handlers: ContactEventHandlerMap

      联系人事件处理器集合，按需实现对应回调。

    可监听事件

    onContactInvited, onContactDeleted, onContactAdded, onContactRefuse, onContactAgreed, onContactInfoUpdated

    ContactEventName

    Returns void

    注册完成后无返回值。

    Example: 调用示例（监听联系人添加事件）

    client.contactManager.addEventHandler('contact-ui', {
      onContactAdded: event => {
        console.log(event.from);
      },
    });
