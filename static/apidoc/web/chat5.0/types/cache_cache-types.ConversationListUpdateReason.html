Type Alias ConversationListUpdateReason

ConversationListUpdateReason: "conversation" | "profile" | "message" | "local"

会话列表更新原因。

  • conversation：会话列表同步或会话缓存基线变化；
  • profile：好友或用户资料补全导致会话展示信息（例如，昵称或头像）变化；
  • message：收发消息导致最后一条消息、未读数或会话排序发生变化；
  • local：触发了本地会话操作，如置顶、标记、删除会话等。
