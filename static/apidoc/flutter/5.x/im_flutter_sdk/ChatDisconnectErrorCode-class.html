ChatDisconnectErrorCode

ChatDisconnectErrorCode class abstract final

ConnectionEventHandler.onDisconnected 携带的断开原因码。

数值与平台 SDK 的错误码一致，SDK 原样透传，因此这里未列出的原因码也可能收到。

原因分为两类：

  • 退出原因：本地登录态已失效，需要重新登录；
  • 连接原因：连接中断但用户仍处于登录态，SDK 会自动重连。

注意：token 过期不会触发 ConnectionEventHandler.onDisconnected， 而是通过 ConnectionEventHandler.onTokenDidExpire 通知。
