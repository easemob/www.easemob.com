Class MessageSearchOption

从服务器搜索消息的参数配置类。

该功能需要在 Console 开通「消息搜索」增值服务。

setKeywordList

  • setKeywordList(keywordList): void

  • 设置搜索关键词。

    可传入单个关键词，或关键词数组。单个关键词会归一为只有一项的数组后再下发。 列表只有一项时按单关键词搜索；多项时按 setKeywordMatchType 匹配。 每个关键词长度为 1-120 个字符，关键词总长度最多 120 个字符，最多支持 5 个关键词。

    Parameters

    • keywordList: string | string[]

      搜索关键词，或关键词数组。

    Returns void

setKeywordMatchType

  • setKeywordMatchType(keywordMatchType): void

  • 设置关键词列表匹配类型。仅当关键词多于一项时生效。

    公开取值与 Android / iOS 一致：OR = 0，AND = 1。

    Parameters

    • keywordMatchType: KeywordListMatchType

      关键词匹配类型。默认 OR。

    Returns void

setMsgTypes

  • setMsgTypes(msgTypes): void

  • 设置要搜索的消息类型。

    可传入单个类型，或类型数组。单个类型会归一为只有一项的数组后再下发。 不设置表示不按类型过滤。

    Parameters

    • msgTypes: ContentType | ContentType[]

      消息类型，或消息类型数组。

    Returns void
